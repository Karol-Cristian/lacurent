# TRUST_AND_MONETIZATION.md

# Principiu central

Separate the analysis engine from monetization.

The physics engine is the core asset of LaCurent. Monetization must not compromise trust in the engine.

---

# Strategic Positioning

LaCurent is not a seller.

LaCurent is not an installer.

LaCurent is not an energy equipment manufacturer.

LaCurent acts as an independent energy decision layer between homeowners and vendors.

---

# Trust Principle

Recommendations must be generated from the building physics model and economic analysis.

Commercial partnerships must never influence technical rankings.

The user should trust that:

* the engine evaluates options objectively;
* the engine identifies the highest-return improvements first;
* the engine remains independent from product suppliers and installers;
* the order of recommendations is not paid placement;
* paid partners may appear only after the technical recommendation is generated.

---

# Correct Flow

```text
Analysis
-> Technical recommendation
-> User decision
-> Optional marketplace / offers / partners
```

---

# Incorrect Flow

```text
Marketplace
-> Commercial recommendation
-> User decision
```

---

# Future Commercial Directions

Nu stergem ideile comerciale. Le pastram ca directii viitoare.

Directii posibile:

* installer marketplace;
* quotation platform;
* photovoltaic partners;
* heat pump partners;
* insulation contractors;
* renovation financing;
* B2B SaaS for auditors;
* B2B SaaS for installers;
* B2B SaaS for renovation consultants;
* affiliate or commission models only after trust is established.

---

# Reguli pentru parteneri

Partenerii pot aparea doar dupa ce:

1. analiza tehnica a fost generata;
2. recomandarea exista independent de partener;
3. utilizatorul intelege motivul recomandarii;
4. utilizatorul cere sau accepta explorarea ofertelor.

Partenerii nu pot cumpara pozitia in topul recomandarilor tehnice.

---

# Reguli pentru oferte

O oferta poate recalcula costul si recuperarea investitiei.

O oferta nu poate crea artificial o recomandare tehnica.

Corect:

* modelul recomanda izolarea podului;
* utilizatorul vrea sa exploreze costuri;
* furnizorii pot aparea pentru acea masura;
* payback-ul se recalculeaza cu pretul real.

Gresit:

* furnizorul plateste;
* recomandarea urca artificial;
* utilizatorul primeste o prioritate comerciala mascata ca analiza tehnica.

# Success metrics

## Short-term

* number of homes modeled;
* report completion rate;
* accuracy of physics engine;
* number of validated assessment cases;
* percentage of users who understand the report;
* number of users who add real consumption/factures.

## Medium-term

* number of scenarios simulated;
* number of users who request improvement options;
* number of validated savings estimates;
* number of partner conversations.

## Long-term

* percentage of residential energy investment decisions evaluated through LaCurent before execution;
* total value of energy investments influenced by LaCurent;
* number of renovation projects routed through LaCurent;
* trust score from homeowners;
* repeat usage before major home energy purchases.
