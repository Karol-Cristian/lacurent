# docs/ui-placeholders-brief.md

## Goal

Create animated, presentational placeholders for missing LaCurent modules.

These components are decorative status panels only. They must not imply that the underlying modules are functional.

## Components

1. PhysicsEnginePlaceholder
2. LumenPlaceholder
3. DecisionEnginePlaceholder

## Shared style

- Dark retro-futuristic laboratory HUD
- Subtle grid background
- Thin luminous SVG lines
- Soft glow
- Monospace micro-labels
- Smooth looping animations
- Must support prefers-reduced-motion

## Physics Engine visual

Theme: energy core, equations, flux, solver calibration.

Elements:
- central reactor/core
- orbiting particles
- animated sine wave
- floating equations:
  - P = U × I
  - E = P × t
  - Q = m × c × ΔT
  - η = Eout / Ein
- labels:
  - CALIBRATING MODEL
  - SOLVING ENERGY BALANCE
  - THERMAL FLOW CHECK
