## Validation Status Rules

- `executable`: use only when all required numeric inputs, units, assumptions, expected outputs, and source rows are complete and visually verified.
- `partially_executable_fixture_001`: a narrowed reviewed fixture is executable, but the broader indexed example is not fully executable.
- `partially_executable_fixture_002`: a narrowed reviewed thermal-bridge fixture is executable, but missing bridge lengths and L2D values still block the broader indexed example.
- `partially_executable_fixtures_007_008_012_013_014`: narrowed final-primary-CO2, service final-primary, displayed RER, class interval, and utility-inclusion threshold-recalculation fixtures are executable, but page 523 heating prose typo, page 527 electric CO2 worked-example factor inconsistency, general RER perimeter, Anexa B class-label trace, reference-building/CPE context, virtual ventilation consumption, overheating indicator, and mixed-use averaging still block the broader indexed example.
- `partially_executable_fixtures_004_005_006`: narrowed reviewed transmission-summary, ventilation-summary, and monthly-balance fixtures are executable, but full transfer derivation, exact eta values, Apr/Sep/Oct Figure 2.18 source conflict, independent ventilation constants, H final and system/final-energy rows still block the broader indexed example.
- `partially_executable_fixtures_001_003`: narrowed reviewed geometry/envelope fixtures are executable, but the broader indexed example is not fully executable.
- `partially_executable_fixtures_002_003`: narrowed reviewed thermal-bridge fixtures are executable, but missing bridge lengths and L2D values still block the broader indexed example.
- `blocked_missing_climate_dataset`: monthly exterior temperature, annual exterior temperature, solar irradiation, or orientation/tilt climate data is missing.
- `blocked_missing_dhw_dataset`: reserved for missing DHW demand table values. No current candidate uses this as the primary blocker after Tabel 3.3.1 extraction and useful-demand helper creation.
- `blocked_missing_table`: source table rows are visually unclear, unverified, metadata-only, or not machine-readable.
- `blocked_missing_inputs`: the source has no calculated outputs or the full input chain is incomplete.

## Orchestrator Boundary Note

`INVESTIGATION_008_MINIMAL_MC001_ORCHESTRATOR_BOUNDARY` recommended that the first orchestrator fixture be Level 0. `FIXTURE_015_MINIMAL_MC001_ORCHESTRATOR_SUMMARY` implements that recommendation as a pure summary aggregator over Fixture 001-014 outputs and explicit blockers.

`INVESTIGATION_009_LEVEL_1_EXPLICIT_INPUT_PACK` defines the required Level 1 input-pack sections. `FIXTURE_016_LEVEL_1_CORE_COMPONENT_ORCHESTRATOR` implements only the narrow recommended core: transmission, ventilation, final/primary/CO2, and explicit blockers. `FIXTURE_017_LEVEL_1_MONTHLY_HEATING_ORCHESTRATION` adds optional monthly heating summary composition over Fixture 006 rows without changing Figure 2.18 behavior. `FIXTURE_018_LEVEL_1_FAIL_CLOSED_HARDENING` tightens that boundary so missing sections, missing fields, invalid units, non-finite numbers, hidden Apr/Sep/Oct status changes, missing blockers, and readiness claims fail closed. `FIXTURE_020_REGISTRY_CONTRACT_INPUT_BUILDER_GATE` adds the Phase C pre-orchestration contract gate for normative registry records and raw auditor input. `FIXTURE_021_ENVELOPE_FROM_AUDITOR_INPUT` adds the Phase D pre-orchestration envelope input builder for source-backed exterior envelope input only. Class assignment, DHW useful/display-only rows, RER display arithmetic, utility threshold recalculation, complete envelope/Htr readiness, and Level 2 full MC001 auditor behavior remain out of scope.
