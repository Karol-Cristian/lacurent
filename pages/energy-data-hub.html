PE SCURT

Cum citesti modelul

1Cladirea pierde energie

Peretii, acoperisul, pardoseala, ferestrele si ventilatia determina cat de repede se pierde caldura.

2Motorul calculeaza necesarul

Necesarul util spune cata energie cere locuinta pentru confort, inainte sa ne uitam la centrala, soba sau pompa.

3Sistemele transforma necesarul in consum

Un sistem eficient consuma mai putin pentru acelasi confort. De aici apare energia finala.

4Rezultatul devine decizie

Energia finala devine energie primara, CO2, clasa estimata si scenarii de imbunatatire.

FORMULE ESENTIALE

Ce calcule se aplica

Izolatie stratR_layer = d / lambda

Cu cat R este mai mare, cu atat stratul izoleaza mai bine.

Pierdere elementU = 1 / R_total

Cu cat U este mai mic, cu atat elementul pierde mai putina caldura.

Punti termiceU' = (U x A + sum(psi x length)) / A

Adauga pierderile din colturi, contururi si imbinari.

Transfer termicH_element = U' x A

Transforma calitatea elementului si aria lui in pierdere W/K.

VentilatieHve = 0.34 x airflow x (1 - eta)

Arata pierderea prin aerisire, infiltratii sau ventilatie mecanica.

Necesar lunarQheat = max(0, Qloss - gains useful)

Energia ceruta de cladire pentru confort, inainte de sistem.

Sistem incalzireeta = emission x distribution x storage x generation x control

Randamentul total al sistemului, construit din subsisteme.

Energie finalaFinalEnergy = UsefulDemand / eta

Energia platita efectiv la combustibil sau electricitate.

Apa caldaQdhw = liters x rho x c x deltaT / 3600

Necesar fizic simplificat pentru prepararea apei calde.

RacireCoolingFinal = CoolingDemand / SEER

Consum electric estimat pentru racire.

Energie primaraPrimary = FinalEnergy x factor

Transforma energia finala in indicator comparabil energetic.

EmisiiCO2 = FinalEnergy x kgCO2/kWh

Emisii estimate pe carrier.

CE INSEAMNA REZULTATELE

Traducere din termeni tehnici

UCalitatea izolatiei

Mic este bine. Un perete cu U mic pierde mai putina caldura.

HtrPierderi prin anvelopa

Arata pierderea totala prin pereti, acoperis, pardoseala, ferestre si usi.

HvePierderi prin aer

Arata cat pierzi prin infiltratii, aerisire sau ventilatie fara recuperare.

QH,ndNecesar de incalzire

Cata energie cere casa ca spatiu, indiferent ce sistem ai.

FinalCe consumi efectiv

Depinde de soba, centrala, pompa de caldura, boiler si auxiliare.

PrimaryImpact energetic total

Indicator folosit pentru comparatii energetice, estimat pe carrier.

CO2Impact de mediu

Estimare a emisiilor asociate energiei finale.

ClassIncadrare estimativa

Clasa LaCurent este orientativa si nu este certificat oficial.
